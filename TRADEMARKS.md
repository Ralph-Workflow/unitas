## How unitas uses third-party names

Third-party names appear in unitas only to state facts about compatibility
and interoperability, for example which project formats unitas reads or which
version's documented behavior a feature follows.

Some names also appear as identifiers in code, such as the `UnityEngine` C#
namespace. Existing scripts refer to those identifiers, so unitas must expose
them for those scripts to compile and run unchanged. Their presence does not
mean that unitas contains, or is derived from, the trademark owner's software.
unitas is written independently, under the rules in
[CONTRIBUTING.md](CONTRIBUTING.md#independent-implementation).

## Rules for the project and for redistributors

* Never use a third-party logo, icon, or visual identity.
* Never use a third-party mark in the name of unitas, of a component, of a
  build, or of a distribution, or in a way that suggests the owner made,
  endorsed, or certified it.
* Use only as much of a name as a statement of compatibility needs, in plain
  text.
